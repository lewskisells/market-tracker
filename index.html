Google Sheets Historical Data (Setup)
To enable automatic chart history from your Google Sheet:
1. Open your Ventura Market Memory File Google Sheet
2. Go to File → Share → Publish to web
3. Select Tab: 6 - Full History and format Comma-separated values (.csv)
4. Click Publish and copy the URL
5. Paste it in the field below and click Save
